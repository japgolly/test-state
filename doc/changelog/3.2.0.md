# 3.2.0

* Add `RunCallbacks` to inject behaviour around every action as it executes. Usage example:

  ```scala
  val callbacks = dsl.runCallback.aroundActions.timed((_, name, _, dur) =>
    println(s"Action [${name.value}] completed in $dur")
  )

  val report = plan
    .test((???)
    .withInitialState(???)
    .withRef(???)
    .withCallbacks(callbacks) // add here to use
    .run()
  ```

* Fix `ActionOps.modS` erroneously modifying an `Action.Group`'s pre-execution condition.
* Fix `DomZipper.DomCollection` not enforcing container constraints on raw query results when `.filter` is applied (e.g. `collect01` now strictly fails if >1 elements match the raw query).
* Fix `DomZipper.selectedOption` and `DomZippersFastAndSlow.selectedOption` reading static HTML attributes instead of live DOM selection in browser-backed zippers, and not defaulting to the first option when none are explicitly marked selected.
* Fix `DomZipperBase.child` ignoring `name` on success and masking the error message when 0 children match.
* Fix `DomZipperJs.value` throwing `TypeError` instead of failing cleanly when `.value` is `undefined`.
* Fix `DomZipperJsoup.body`, `DomZipperJsoup.parseHtml`, and `FastDomZipperSelenium.html` starting at the Jsoup `Document` (`#root`) instead of `<body>` / `<html>`.
* Fix `DomZipperJsoup` and `DomZippersFastAndSlow` (including `FastDomZipperSelenium`) applying `htmlScrub` redundantly on `outerHTML` and `innerHTML`.
* Fix `DomZippersFastAndSlow` (including `FastDomZipperSelenium`) `checked` reading static HTML attributes for checkboxes instead of delegating to the live DOM.
* Fix `DomZippersFastAndSlow` (including `FastDomZipperSelenium`) `startConsistencyCheck()` and `ensureConsistency()` not checking the underlying live DOM.
* Fix `DomZippersFastAndSlow` (including `FastDomZipperSelenium`) `value` reading static HTML attributes instead of delegating to the live DOM.
* Fix `Dsl#equalByWhenDefined` passing instead of skipping when undefined.
* Fix `Dsl#equalWhenDefined(None)` naming step as `"should be None."`.
* Fix `Dsl#testAround` passing `(after, before)` instead of `(before, after)`.
* Fix `ExecutionModel.scalaFuture` leaking `java.util.Timer` threads and hanging promises on synchronous exceptions in `schedule` and `doFinally`.
* Fix `FocusColl.map` and `FocusColl.filter` returning single-use `Iterator`s, and prevent iterator exhaustion during `elemChanges` retries.
* Fix `GrowthStrategy` to validate arguments to `maxBrowsers` and `maxTabs` are `> 0`.
* Fix `MultiBrowser.par` to shutdown thread-pool when exceptions are thrown
* Fix `MultiBrowser` leaking temporary setup tab when `onNewDriverWithTempTab` throws an exception.
* Fix `MultiBrowser` temporary setup tab triggering `onNewTab` and inflating tab counts for `GrowthStrategy`.
* Fix `NamedOps` renaming bugs in `Invariant.Delta`, `NamedError`, `Sack.CoProduct`, and `TestStateNFEBA.thruAfter`.
* Fix `RunCallbacks` `aroundActions.before` running after actions instead of before.
* Fix `RunCallbacks` completion callbacks (`after` / `timed`) being skipped when an action throws an exception.
* Fix bitwise shift operator precedence bug in `ScrollLogic.Line.startAndSize` (`SeleniumExt.scala`)
* Fix bug where retrying post-conditions on an action group would revert state updates made inside the group.
* Fix cross-thread locking and unlocking in `ext-selenium`'s `Mutex.monadic` (used by `Tab.useM` and `Dsl.withSeleniumTab`).
* Fix delta invariants being reported under "Post-conditions" instead of "Invariants".
* Fix exception recovery in `ExecutionModel[AsyncCallback]`.
* Fix post-conditions not being retried for `Action.SubTest`.
* Fix potential `NullPointerException` in `SeleniumExt#classes`
* Fix pre-action `Around` check before-functions being evaluated after the action.
* Fix pre-check retry in `Action.Group` and `Action.SubTest` discarding the re-observed observation/state.
* Fix pre-condition retry in `Action.Single` using `Retry.Scope.Action` instead of `Retry.Scope.PreConditions`.
* Optimise `Action.Group.Cond`: short-circuit `|+|` when false, check right-identity with `Cond.always`, and preserve `Cond.always` identity on `mapE`, `mapR`, and `mapOS`.
