# 3.2.0

* Add `RunCallbacks` to inject behaviour around every action as it executes. Usage example:

  ```scala
  val callbacks = dsl.runCallback.aroundActions.timed((_, name, _, dur) =>
    println(s"Action [${name.value}] completed in $dur")
  )

  val report = plan
    .test((???)
    .withInitialState(???)
    .withRef(???)
    .withCallbacks(callbacks) // add here to use
    .run()
  ```

* Fix `Action.Single` preparation exceptions (`.when` / `.unless` / `pmapR` / `pmapO`) crashing `Runner`.
* Fix `ActionOps.modS` erroneously modifying an `Action.Group`'s pre-execution condition.
* Fix `DomZipper.DomCollection.traverse` overflowing the stack on large collections.
* Fix `DomZipper.DomCollection` dropping prior container validation on `collect01`, `collect0n`, and `collect1n` conversions.
* Fix `DomZipper.DomCollection` not enforcing container constraints on raw query results when `.filter` is applied (e.g. `collect01` now strictly fails if >1 elements match the raw query).
* Fix `DomZipper.DomCollection` skipping container validation in `head`, `last`, and `singleton` when unfiltered.
* Fix `DomZipper.selectedOption` and `DomZippersFastAndSlow.selectedOption` reading static HTML attributes instead of live DOM selection in browser-backed zippers, and not defaulting to the first option when none are explicitly marked selected.
* Fix `DomZipperBase.child` ignoring `name` on success and masking the error message when 0 children match.
* Fix `DomZipperJs.value` throwing `TypeError` instead of failing cleanly when `.value` is `undefined`.
* Fix `DomZipperJsF.classes` returning `Set.empty` on SVG elements.
* Fix `DomZipperJsF.dynamicMethod` returning `Some(null)` when a JS property is `null`.
* Fix `DomZipperJsoup.body`, `DomZipperJsoup.parseHtml`, and `FastDomZipperSelenium.html` starting at the Jsoup `Document` (`#root`) instead of `<body>` / `<html>`.
* Fix `DomZipperJsoup` and `DomZippersFastAndSlow` (including `FastDomZipperSelenium`) applying `htmlScrub` redundantly on `outerHTML` and `innerHTML`.
* Fix `DomZipperSeleniumF._parent` wrapping closure allocation in `F.attempt` instead of evaluating `dom().parent()(driver)`.
* Fix `DomZipperSeleniumF.getAttribute` crashing with `JavascriptException` on non-element nodes.
* Fix `DomZippersFastAndSlow.cmap` throwing when elements disappear from the live DOM.
* Fix `DomZippersFastAndSlow` (including `FastDomZipperSelenium`) `checked` reading static HTML attributes for checkboxes instead of delegating to the live DOM.
* Fix `DomZippersFastAndSlow` (including `FastDomZipperSelenium`) `startConsistencyCheck()` and `ensureConsistency()` not checking the underlying live DOM.
* Fix `DomZippersFastAndSlow` (including `FastDomZipperSelenium`) `value` reading static HTML attributes instead of delegating to the live DOM.
* Fix `Dsl#equalByWhenDefined` passing instead of skipping when undefined.
* Fix `Dsl#equalWhenDefined(None)` naming step as `"should be None."`.
* Fix `Dsl#testAround` passing `(after, before)` instead of `(before, after)`.
* Fix `ErrorHandler.attempt` (`dom-zipper`) passing `null` when an exception's `getMessage` is `null`.
* Fix `ErrorHandler.name` printing `"WithCause(...)"` on exception
* Fix `ErrorHandler.toStringWithStackTrace` duplicating error message on the first two lines.
* Fix `ExecutionModel.scalaFuture.doFinally` dropping the primary exception instead of recording it as suppressed when both `main` and `last` fail.
* Fix `ExecutionModel.scalaFuture` leaking `java.util.Timer` threads and hanging promises on synchronous exceptions in `schedule` and `doFinally`.
* Fix `ExtNyaya.genActionsBy` generating all samples upfront from the initial `ROS` instead of per sample step.
* Fix `ExtScalaJsReact.executionModelAsyncCallback` typo (`executionModalAsyncCallback` deprecated) and mark it `implicit`.
* Fix `ExtScalaJsReact.executionModelAsyncCallback`: suspend by-name arguments in `doFinally`, `schedule`, and `recover`, and skip `delayMs` when `delay <= 0`.
* Fix `FastDomZipperSeleniumF` applying `htmlScrub` redundantly before Jsoup parsing.
* Fix `FocusColl.map` and `FocusColl.filter` returning single-use `Iterator`s, and prevent iterator exhaustion during `elemChanges` retries.
* Fix `GrowthStrategy` to validate arguments to `maxBrowsers` and `maxTabs` are `> 0`.
* Fix `JsDomExt#addStyleTag` and `SeleniumExt#addStyleTag` failing when `<head>` is absent.
* Fix `MultiBrowser.par` to shutdown thread-pool when exceptions are thrown
* Fix `MultiBrowser` leaking temporary setup tab when `onNewDriverWithTempTab` throws an exception.
* Fix `MultiBrowser` retaining an uninitialised browser when `onNewDriver` throws an exception.
* Fix `MultiBrowser` running `onNewTab` inside `outerMutex` and before `onNewDriverWithTempTab` (which could also deadlock the browser if `onNewTab` threw).
* Fix `MultiBrowser` temporary setup tab triggering `onNewTab` and inflating tab counts for `GrowthStrategy`.
* Fix `MultiBrowser` unlocking the browser mutex before closing the temporary setup tab.
* Fix `Mutex.monadic` retry loop overflowing the stack on synchronous `ExecutionModel`s.
* Fix `Mutex.unlock` allowing a non-owning thread to unlock a synchronously acquired lock.
* Fix `NamedOps` renaming bugs in `Invariant.Delta`, `NamedError`, `Sack.CoProduct`, and `TestStateNFEBA.thruAfter`.
* Fix `NameUtils` evaluating `focusName` and `verb` strictly rather than lazily.
* Fix `ReportFormat.Default.addColour` ignoring `uncoloured.indent` and hardcoding `"  "`.
* Fix `ReportFormat.Default.StatsFormat.formatDuration` off-by-one time unit checks for durations under 1ms.
* Fix `RunCallbacks` `aroundActions.before` running after actions instead of before.
* Fix `RunCallbacks` completion callbacks (`after` / `timed`) being skipped when an action throws an exception.
* Fix `Runner.runPreChecksWithRetry` re-running pre-checks on stale `ROS` and inflating `stats.checks` when `reObserve()` fails.
* Fix `Runner` action and post-condition retries discarding the latest attempt/observation on subsequent `reObserve()` failures.
* Fix `SeleniumExt#parent` returning the `#document` node instead of `null` on `<html>`.
* Fix `Tab`: execute `afterFirstUse` / `aroundFirstUse` around the first use (using `ExecutionModel[M]` in `useM`) instead of before it.
* Fix bitwise shift operator precedence bug in `ScrollLogic.Line.startAndSize` (`SeleniumExt.scala`)
* Fix bug where retrying post-conditions on an action group would revert state updates made inside the group.
* Fix cross-thread locking and unlocking in `ext-selenium`'s `Mutex.monadic` (used by `Tab.useM` and `Dsl.withSeleniumTab`).
* Fix delta invariants being reported under "Post-conditions" instead of "Invariants".
* Fix exception recovery in `ExecutionModel[AsyncCallback]`.
* Fix post-conditions not being retried for `Action.SubTest`.
* Fix potential `NullPointerException` in `SeleniumExt#classes`
* Fix pre-action `Around` check before-functions being evaluated after the action.
* Fix pre-check retry in `Action.Group` and `Action.SubTest` discarding the re-observed observation/state.
* Fix pre-condition retry in `Action.Single` using `Retry.Scope.Action` instead of `Retry.Scope.PreConditions`.
* Improve `DomZipper` failure messages in `needAttribute`, `value`, `checked`, `parent`, `domAs`, and `domsAs` by including `DESC` and `HTML` context via `enrichErr`.
* Improve `Dsl#{de,in}crease{,By}` failure messages by including initial and expected values.
* Improve `ExtScalaJsReact` `.domZipper` error message when `ReactDOM.findDOMNode` returns `None`.
* Optimise `Action.Group.Cond`: short-circuit `|+|` when false, check right-identity with `Cond.always`, and preserve `Cond.always` identity on `mapE`, `mapR`, and `mapOS`.
* Optimise `Action.Single` to avoid evaluating `actionFn` twice when pre-checks pass without retry.
* Optimise `DomZipper.DomCollection`: evaluate `.filter` lazily, avoid intermediate allocations in `mapDoms`/`traverseDoms`/`mapExtracts`/`traverseExtracts`, and reuse `ErrorHandler` container instances.
* Optimise `DomZipperBase.child` to avoid intermediate zipper/collection allocations.
* Optimise `DomZipperBase` and `DomZippersFastAndSlow` to avoid intermediate zipper/collection allocations in `count` and `exists`.
* Optimise `DomZipperJsF` and `DomZipperSeleniumF` to skip querying immediate children when a child CSS selector matches nothing.
* Optimise `DomZipperSeleniumF._parent` to cache the resolved `WebElement` instead of re-querying on every operation.
* Optimise `DomZipperSeleniumF.matches` to evaluate `Element.matches` directly in the browser instead of querying the entire document.
* Optimise `ExecutionModel.scalaFuture.schedule` to bypass `Timer` when `delayMs <= 0` and avoid some allocations.
* Optimise `HtmlScrub`: make `empty` and `joinLines` `val`s and short-circuit `>>` on `HtmlScrub.empty`.
* Optimise `JsoupElement`: use direct element evaluation in `matches` and `selectChildren`, and avoid allocating `Attributes` in `attr` and `isSelected`.
