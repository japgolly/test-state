# 3.3.0

* Fix `DomZipperBase.child` ignoring `name` on success and masking the error message when 0 children match.
* Fix `DomZipperJsoup.body`, `DomZipperJsoup.parseHtml`, and `FastDomZipperSelenium.html` starting at the Jsoup `Document` (`#root`) instead of `<body>` / `<html>`.
* Fix `DomZippersFastAndSlow` (including `FastDomZipperSelenium`) `startConsistencyCheck()` and `ensureConsistency()` not checking the underlying live DOM.
* Fix `Dsl#testAround` passing `(after, before)` instead of `(before, after)`.
* Fix `NamedOps` renaming bugs in `Invariant.Delta`, `NamedError`, `Sack.CoProduct`, and `TestStateNFEBA.thruAfter`.
* Fix `RunCallbacks` `aroundActions.before` running after actions instead of before.
* Fix `RunCallbacks` completion callbacks (`after` / `timed`) being skipped when an action throws an exception.
* Fix bitwise shift operator precedence bug in `ScrollLogic.Line.startAndSize` (`SeleniumExt.scala`)
* Fix bug where retrying post-conditions on an action group would revert state updates made inside the group.
* Fix cross-thread locking and unlocking in `ext-selenium`'s `Mutex.monadic` (used by `Tab.useM` and `Dsl.withSeleniumTab`).
* Fix exception recovery in `ExecutionModel[AsyncCallback]`.
